# Verification and remaining limitations

Version 0.7.10 is a source-only preview. Recipients build the native helpers and download models on their own Mac. No maintainer Apple Developer account, signing certificate, native executable or model weight is required in the release.

## Verified for 0.7.10 interaction stability

Dialogs keep a fixed top anchor as Advanced, feedback or cooldown content changes. Their sticky headings cover the top edge while scrolling. The library and reader reserve constant end space for the feedback dock; clearing it no longer changes scroll height. Import labels describe a bounded run, and API-call limits explain their relation to posts and spending.

Normal UI processing uses a shared pending-item condition for status and queue selection. In an isolated ten-item SQLite library, one eligible item queued exactly once across two concurrent requests; completed bookmarks and existing paused/failed jobs stayed untouched. Explicit item rebuild remained available. An empty pending action left the library paused. No worker or provider ran in this rehearsal.

The production panel in a controlled MCP host showed zero heading movement on desktop and 390-pixel dark layouts when expanding Advanced. A controlled settings error/cooldown retained the dialog anchor and rolled back the failed setting. Clearing feedback at the end of the library changed neither scroll position nor scroll height. The Process dialog displayed one eligible bookmark and sent `scope="pending"`. This is a simulated host check, not a claim of zero layout shifts in every desktop host configuration. No real import or processing ran. Installation is verified separately.

## Verified for 0.7.9 bulk-processing controls

Import saves inventory/text/metrics/folders without starting media processing. Process saved bookmarks is separate. Persistent item/request limits pause a run and can be increased before explicitly resuming. Defaults and their scope are documented in [Architecture](ARCHITECTURE.md#processing-and-temporary-storage); these counters are not a monetary spending cap.

New videos use local transcripts, OCR and embeddings, without subscription descriptions. Existing completed video descriptions remain saved; unfinished video-description stages are cancelled without deleting originals. Video downloads use yt-dlp with a 480p target, adjustable in Advanced. Five-minute speech segments preserve absolute timestamps and use a one-second overlap. Tiny codec-padding tails merge into the preceding segment, and frame selection stops at the last real frame. The former 192 MiB video cap and four-hour ceiling are removed. The default temporary budget is 8 GiB plus a separate 2 GiB free-disk reserve; concurrent workers share reservations. Pausing/restarting releases unused reservations, retaining actual files. Normal service termination reaps managed downloads/transcribers before releasing its lock. Abrupt OS/process termination still requires restart recovery and is not a guarantee that every external process has exited immediately.

An isolated real SQLite/HTTP rehearsal imported 135 generated posts over two pages, checked the empty-folder endpoint, and stopped exactly at item 37. Resuming consumed the cached remainder without another request; reaching the X request limit paused the run. Twelve concurrent callers claimed only seven permitted requests, with the count retained in a fresh interpreter. HTTP and streamed provider limit responses established account cooldowns without blocking local work. Diagnostic exports included budget state while excluding account IDs, source URLs and bookmark text. A migrated copy retained all 204 saved evidence chunks byte-for-byte. Full backup/restore retained evidence and returned paused.

An actual yt-dlp download from a local HTTP fixture retrieved a generated two-hour MP4. Planning created 24 speech segments and 900 video windows with no video-description stages. Native Parakeet recovered the repeated controlled sentence in the final five-minute segment, with word times from 6902.36 to 7195.4 seconds; final-window frame decoding/OCR also completed. This is a repeated synthetic clip, not a two-hour real-podcast accuracy or throughput benchmark. All 900 windows were not processed as part of that rehearsal. A monitored subprocess was interrupted and resumed with its original preserved; competing cache admission correctly waited instead of evicting unfinished media.

Two video-only retrieval queries on a copied real sample ranked the expected bookmark first using saved video embeddings, excluding descriptions, transcript and post-text chunks from the search. This supports the chosen recall path on those examples, not every silent demo or visual detail. Low resolution, sampling, English speech recognition and unavailable sources remain quality limits.

The built panel was exercised through its MCP/SDK host harness: separate Import/Process controls, a direct processing action after import, themed budget/storage menus, persisted preferences without starting work, budget extension without resuming, and a 390-pixel layout without horizontal overflow. Saving a setting retains keyboard focus. The host/composer and provider actions were simulated; no real import or provider inference was performed during UI validation. Installation verification is recorded separately; an already-open desktop panel may need reopening.

## Remaining boundaries

- **Fresh recipient:** a completely fresh second-Mac dependency/model install, its X OAuth and full personal import have not been verified. Setup must run both preflights and verify actual MCP discovery before reporting ready. Source/build/archive success is not installation proof.
- **Reported 300-bookmark cutoff:** there is no deliberate 300-bookmark inventory cap. Its exact cause on the friend's device remains unconfirmed without saved diagnostics. More credits do not remove rate limits, account access restrictions or provider history limits. Export diagnostics before retrying or buying more credits.
- **Coverage:** exhausted API pages do not prove X exposes every historical bookmark. Missing metrics stay unknown. Inaccessible/deleted media remains unavailable; partial folders stay explicit. Parent/quote scope is one hop, with no thread discovery.
- **Visual/speech quality:** one frame per second can miss brief events or tiny text; descriptions may be wrong. Parakeet's English model is not a multilingual guarantee. PDF text extraction does not interpret page graphics. The controlled examples establish basic operation, not arbitrary-source accuracy.
- **Browser/Reader:** A live public Jina Reader request returned 4,900 readable words in the expected format; fallback routing was separately verified with controlled responses. Availability and extraction quality still vary. Forwarding is restricted to recognized public or owner-approved hosts; other sites wait for a desktop agent. Private login/session access must use the appropriate browser profile, and recovery cannot bypass authentication or challenges. Authenticated real-site recovery has not been rehearsed.
- **Subscription:** recipient eligibility/models and shared usage allowances may differ. The provider initially showed an error/security verification before callback; personal completion succeeded. Such provider-side sign-in failures cannot be repaired by spending X credits or substituting Platform API billing.
- **Storage/updates:** existing originals and historical logs/scans are preserved; the bounded temporary-media policy applies to newly managed media. Older retained files need a separately authorized cleanup. Backups exclude disposable media and OAuth credentials; unfinished work may need retrieval after restore. Model weights and durable vectors/text consume storage outside the temporary budget.

Setup and updates finish paused. Do not resume old work, start imports, refresh paid sources or publish a release as an incidental verification step. Diagnostic exports are local and sanitized; private raw logs, registration files, tokens, callback URLs and library content must never be included in public reports.
