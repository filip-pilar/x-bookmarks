# Verification and remaining limitations

Version 0.7.7 is a source-only preview. Recipients build the native helpers and download models on their own Mac. No maintainer Apple Developer account, signing certificate, native executable or model weight is required in the release.

## Verified for 0.7.7 model selection

Settings loads the active ChatGPT account's model catalog automatically. Successful results are reused for five minutes and invalidated when account access changes. The compact selector uses provider display names; a sole available, already-selected model is a plain value. One connected account no longer produces a redundant account picker. Loading preserves the model row's height, and catalog errors/empty results provide a local retry. Unavailable saved models require an explicit replacement; the panel never changes the selected model automatically.

The maintainer's live account catalog returned eight models. Browser rehearsals with the built panel, a copied library and controlled provider responses covered loading geometry, successful selection, failure rollback, retry, single/empty catalogs, unavailable saved models, account changes while requests were pending, cached reopening and keyboard focus in a narrow dark layout. No description generation or real account/model change was performed. The browser host remains simulated; already-open desktop panels need reopening after installation.

## Verified for 0.7.6 filters, search and Settings

Filters open in an anchored popover instead of inserting content above the library. Active filters use a fixed-position indicator, with selections and Reset inside the popover. Nested menus, Escape, outside interaction and keyboard focus are coordinated. The popover and its menus respect the reading area's composer clearance.

Empty/whitespace-only Search leaves an unfiltered library or reader in place without another request. A dedicated clear control and Escape return active search results to the library. Late responses from a cleared query cannot replace the restored list. Repeating an already loaded query does not reload it.

Settings pairs account names with their provider, exposes the description model directly, groups account management separately, labels expired sign-in and plan permission distinctly, and shows processing state, diagnostic privacy and the installed UI version. Browser rehearsals used the real panel/SDK with a copied library and controlled search/account responses; no provider or import actions were performed. The desktop shell/composer remain simulated, and already-open panels require reopening after installation.

## Remaining boundaries

- **Fresh recipient:** a completely fresh second-Mac dependency/model install, its X OAuth and full personal import have not been verified. Setup must run both preflights and verify actual MCP discovery before reporting ready. Source/build/archive success is not installation proof.
- **Reported 300-bookmark cutoff:** there is no deliberate 300-bookmark inventory cap. Its exact cause on the friend's device remains unconfirmed without saved diagnostics. More credits do not remove rate limits, account access restrictions or provider history limits. Export diagnostics before retrying or buying more credits.
- **Coverage:** exhausted API pages do not prove X exposes every historical bookmark. Missing metrics stay unknown. Inaccessible/deleted media remains unavailable; partial folders stay explicit. Parent/quote scope is one hop, with no thread discovery.
- **Visual/speech quality:** one frame per second can miss brief events or tiny text; descriptions may be wrong. Parakeet's English model is not a multilingual guarantee. PDF text extraction does not interpret page graphics. The controlled examples establish basic operation, not arbitrary-source accuracy.
- **Browser/Reader:** A live public Jina Reader request returned 4,900 readable words in the expected format; fallback routing was separately verified with controlled responses. Availability and extraction quality still vary. Forwarding is restricted to recognized public or owner-approved hosts; other sites wait for a desktop agent. Private login/session access must use the appropriate browser profile, and recovery cannot bypass authentication or challenges. Authenticated real-site recovery has not been rehearsed.
- **Subscription:** recipient eligibility/models and shared usage allowances may differ. The provider initially showed an error/security verification before callback; personal completion succeeded. Such provider-side sign-in failures cannot be repaired by spending X credits or substituting Platform API billing.
- **Storage/updates:** existing originals and historical logs/scans are preserved; the bounded temporary-media policy applies to newly managed media. Older retained files need a separately authorized cleanup. Backups exclude disposable media and OAuth credentials; unfinished work may need retrieval after restore. Model weights and durable vectors/text consume storage outside the temporary budget.

Setup and updates finish paused. Do not resume old work, start imports, refresh paid sources or publish a release as an incidental verification step. Diagnostic exports are local and sanitized; private raw logs, registration files, tokens, callback URLs and library content must never be included in public reports.
